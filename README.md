# Number Hunter

Number Hunter is a small number-guessing game made using HTML, CSS and JavaScript.

## How to Play
- The computer randomly selects a number between 1 and 20.
- Enter your guess in the input box.
- The game tells you if your guess is too high or too low.
- Find the correct number to win!

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## About
I made this project to practise basic JavaScript, random number generation and simple game logic. It is a beginner-friendly project that I can improve with more features in the future.
